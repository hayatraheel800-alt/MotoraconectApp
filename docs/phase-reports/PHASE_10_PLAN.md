# Phase 10 — Dealers

## Status

**Implementation complete.** Comprehensive verification is handled by Phase 14.

## Delivered

- `dealers` dealer profile table.
- Dealer approval lifecycle: DRAFT, PENDING_REVIEW, ACTIVE, SUSPENDED, REJECTED.
- `dealer_inventory` linking dealer-owned vehicles.
- RLS restricting dealer profile and inventory access.
- Dealer owners can only add vehicles they own.
- Mobile dealer directory.
- Mobile dealer registration flow.
- Mobile dealer inventory management.
- Admin dealer approval/moderation policies and queue.

## Deferred / later enhancements

Dealer analytics, richer inventory workflows, bulk inventory tools, dealer messaging context, and comprehensive final verification remain later work.
