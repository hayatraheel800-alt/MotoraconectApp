## Definition of done

Each phase should have implementation, database/schema changes where needed, documentation, and Git commits. Comprehensive automated tests, runtime verification, cross-platform checks, deployment checks, security review, and final acceptance are intentionally consolidated into the final verification/hardening phase unless a lightweight implementation check is required to avoid knowingly broken code.
